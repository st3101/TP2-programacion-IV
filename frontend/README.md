# Lobby — frontend

Frontend de la red social de videojuegos, creado con Angular.

## Ejecutar en desarrollo

Desde esta carpeta:

```powershell
npm start
```

La aplicación se sirve en `http://localhost:4200/`.

## Estado actual

La ruta `/feed` muestra una primera vista del feed con publicaciones de ejemplo. El filtro por jugador, el ordenamiento, los “Me gusta” y el compositor son interacciones locales de la vista previa; todavía no están conectados al backend ni guardan datos.
